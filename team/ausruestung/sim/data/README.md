# Sim-Datensnapshot

Diese Dateien enthalten unveränderte Tabelleninhalte aus den von `sim_f2p.py` benötigten GDD-CSV-Tabellen in `team/gdd/`. CRLF-Zeilenenden der Quelle sind für das Repository zu LF normalisiert. Die Simulation liest diese versionierte Kopie, damit sie auch in einem frischen Klon ausführbar ist.

`MANIFEST.sha256` enthält die SHA-256-Prüfsummen der versionierten CSV-Dateien. Prüfen mit `sha256sum -c MANIFEST.sha256` aus diesem Verzeichnis.
