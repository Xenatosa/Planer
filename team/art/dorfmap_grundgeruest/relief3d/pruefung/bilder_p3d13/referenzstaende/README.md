# Rekonstruierte Referenzstaende

Die Referenzzaehler fuer p3d6, p3d8 und VAR0 stammen zeilenweise aus den bereits gespeicherten `delta_*_p3d12.json` Dateien. `vorher` ist der jeweilige Referenzwert, nicht neu gemessen. Die JSONs bilden dieselben Regel-, Kachel- und Clay-Bildzaehler ab, die `neu/delta.py` liest; fuer Lochpunkte werden bekannte Kachelzaehler durch einen repräsentativen Punkt je Treffer codiert. Diese Referenzen dienen nur zur reproduzierbaren Delta-Auswertung.
